# Gymshark Product Lines Catalog

## How to Choose a Product Line

Match the product line to the creator's niche and audience gender split. Rules:
- Bodybuilding → CBUM
- Powerlifting / Strength → LIFTING
- Running / Cardio / Outdoor → RUNNING
- HIIT / Crossfit / Circuit → HIIT
- Yoga / Pilates → ADAPT
- Physique / Fitness Model / Competition → FORM
- Audience under 45% male → SEAMLESS
- Everything else → TRAINING

---
