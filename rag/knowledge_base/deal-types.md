# Gymshark Creator Deal Types

## Overview

Gymshark uses five deal structures depending on creator tier, audience size, and strategic fit.

---

## Gift Seeding

- **Who gets it:** Nano creators (under ~10K subscribers)
- **Budget:** Product only — kit value £40–150
- **Posting obligation:** None. It is a genuine gift.
- **Tracking:** No UTM links, no promo codes
- **Goal:** Build authentic organic affinity. If they post, great. If not, we've seeded goodwill.
- **Key message to creator:** "No strings attached — we just think you'd love this."

---

## Affiliate

- **Who gets it:** Micro creators (10K–100K subscribers)
- **Budget:** 12% commission on attributed revenue. No upfront fee.
- **Tracking:** Unique promo code + UTM link (both required)
- **Posting obligation:** Encouraged but not contractually required beyond initial agreement
- **Commission rate:** 12% of all revenue attributed to their code/link
- **Promo code format:** GS + first 4 letters of name + 2 random digits (e.g. GSNAO23)
- **Goal:** Performance-based partnership that scales with creator effort

---

## Paid Creative Partnership

- **Who gets it:** Micro/mid creators (20K–300K subscribers)
- **Budget:** £500–5,000 per activation
- **Tracking:** UTM link if possible, but not always required
- **Posting obligation:** Yes — one or more deliverables specified in contract
- **Goal:** Specific campaign activation (product launch, seasonal push)

---

## Brand Ambassador

- **Who gets it:** Mid/macro creators (100K–1M subscribers)
- **Budget:** £2,000–25,000 monthly retainer
- **Tracking:** Full UTM + promo code suite
- **Posting obligation:** Yes — monthly deliverables, exclusivity clauses possible
- **Goal:** Long-term brand association, recurring content, audience trust

---

## Co-Created Collection

- **Who gets it:** Macro/mega creators (500K+ subscribers), elite brand alignment
- **Budget:** £10,000–100,000+ per collection
- **Tracking:** Dedicated product SKUs, full analytics suite
- **Posting obligation:** Major campaign involvement — launch content, appearances
- **Goal:** Full product collab — creator's name/aesthetic on actual Gymshark products

---

## ROI Expectations by Deal Type

| Deal Type | Trackable Revenue? | Expected ROI |
|-----------|-------------------|-------------|
| Gift Seeding | No | Goodwill / organic reach |
| Affiliate | Yes | 5–10x budget via commissions |
| Paid Creative | Partial | 2–5x activation cost |
| Brand Ambassador | Yes | 4–8x monthly retainer |
| Co-Created | Yes | Long-term brand equity + sales |
