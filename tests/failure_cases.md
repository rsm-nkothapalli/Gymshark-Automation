# Section 6A — Anticipated AI Failure Cases

Pipeline under test: Gymshark Influencer Pipeline — Skills 01–03, RAG retrieval, brand-fit analysis, product briefs.

| # | Failure Case | Why It Might Happen | Business Consequence | How the User Would Notice | How Our Process Handles It |
|---|---|---|---|---|---|
| FC-01 | AI invents creator details not in the data | LLM fabricates a competitor affiliation or audience trait not present in creators.csv or the prompt | Outreach based on wrong assumption damages the relationship | Brand-fit analysis cites a "known partnership with Lululemon" that does not appear anywhere | FaithfulnessMetric checks that every claim traces back to the retrieval context |
| FC-02 | Outreach draft contains banned phrases | LLM ignores the explicit NEVER USE list ("amazing", "love your content", etc.) despite clear instructions | Message sounds like a mass-template blast; creator dismisses it immediately | Outreach reads "You are amazing!" or "We love your content" | `validate_message()` detects banned phrases; GEval BannedPhrases check in test suite |
| FC-03 | Draft leaks internal scoring metrics | LLM includes "GFS=7.5" or "risk_level=LOW" from the prompt context in the email body | Creator sees Gymshark is running an automated scoring system; trust collapses | Draft says "Based on your authenticity score of 8/10…" | Prompt rule says "Do NOT reference any internal metrics"; GEval MetricLeakage check |
| FC-04 | Draft exceeds tier word-count limit | Word-count instruction is embedded as natural language ("Max 200 words"); LLM ignores it under complex prompts | Mega-tier recipients (busy, high-status) receive a 300-word email and delete it | Word count > 200 for a mega creator | `validate_message()` catches excess; WordCountCompliance GEval check in test suite |
| FC-05 | Output is generic — no creator-specific observation | Signals and content-style hints in the prompt are ignored; LLM defaults to a template structure | Partnership email indistinguishable from spam; no response | "We love fitness creators like you" with no mention of anything specific to the creator | GEval PersonalizationDepth check; prompt explicitly asks for ONE specific observation |
| FC-06 | Brand-fit analysis sounds confident but contradicts risk signals | LLM smooths over HIGH risk or AMBER brand safety; produces positive-sounding summary regardless | Team approves outreach to a high-risk creator; reputational damage if content misfires | Analysis says "ideal partner" for a creator with 20% flagged comments | GEval RiskAwareness check; test case brand-fit-02 explicitly presents HIGH-risk profile |
| FC-07 | RAG retrieves a weakly matched document | Query is broad (tier + niche + deal type); embedding distance pulls a product-catalog chunk when an outreach-tone chunk was needed | Draft follows product specs instead of tone guidelines; sounds like an ad, not a person | Email uses product jargon ("technical fabrication") rather than conversational language | FaithfulnessMetric score drops when context is irrelevant; human reviews rag_sources shown in UI |
| FC-08 | LLM adds markdown formatting to outreach email | System prompt says "Output only the email", but LLM adds `**bold**` headers or bullet points | Email client renders raw asterisks; looks unprofessional | Recipient sees `**Hi Sophie,**` instead of `Hi Sophie,` | Prompt ends with "No markdown"; GEval FormattingCompliance check |
